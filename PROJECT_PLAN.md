В системе должно быть 3 роли:1. Student / Студент



Студент может:



зарегистрироваться;

войти в аккаунт;

заполнить профиль;

указать колледж;

указать специальность;

загрузить фотографии своих работ;

посмотреть список мест практики;

подать заявку одной кнопкой;

видеть статус заявки.2. Employer / Работодатель



Работодатель может:



зарегистрироваться;

заполнить профиль компании;

добавить место практики;

смотреть список студентов;

смотреть портфолио студента;

видеть заявки студентов;

менять статус заявки: pending / accepted / rejected.3. College Admin / Админ колледжа



Админ колледжа может:



видеть всех студентов своего колледжа;

видеть количество студентов;

видеть количество студентов с портфолио;

видеть количество заявок;

видеть сколько студентов получили accepted;

видеть простую таблицу заявок.5. Главные страницы сайтаPublic Landing Page
